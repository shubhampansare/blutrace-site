# Blutrace — website

Static marketing site for **Blutrace** (PCB design, electronics development & testing).

Single-file `index.html` (vanilla HTML/CSS/JS). Served via **GitHub Pages** at
<https://blutrace.io>.

## Deploy

Push to `main` → GitHub Pages republishes automatically. The custom domain is set by
the `CNAME` file (`blutrace.io`).
